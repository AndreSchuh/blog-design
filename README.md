# Blog do CIMOL

Blog escolar em **AngularJS** que consome uma API REST de postagens e mostra a lista de posts em cards e a página de cada post.

## Funcionalidades
- Listagem de posts com imagem, data, autor e resumo
- Página de detalhe do post (`post.html?id=`)
- Mensagens de carregamento e de erro
- Layout responsivo em CSS puro

## Tecnologias
HTML · CSS · JavaScript · AngularJS 1.8

## Como rodar
Abra o `index.html` no navegador ou use um servidor estático (por exemplo o Live Server do VS Code).

Os posts vêm da API `https://api-fake-blog.onrender.com`. Se ela estiver dormindo, o primeiro carregamento pode demorar.
